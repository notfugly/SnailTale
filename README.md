# SnailTale

SnailTale — прототип текстовой игры на Kotlin. Игроку предстоит прожить семь дней, познакомиться с героиней и принимать решения, влияющие на отношения и ресурсы.

## Сюжет

Главный герой поступает в вуз своей мечты. В первый день он встречает девушку, после чего получает возможность взаимодействовать с ней на протяжении недели. По замыслу авторов, решения игрока приведут к одной из нескольких концовок.

## Игровая механика

У игрока есть четыре показателя:

- отношение героини;
- бюджет;
- энергия;
- готовность.

События предлагают варианты действий. Некоторые варианты доступны только при выполнении условий, а сделанный выбор может изменить показатели игрока.

По замыслу, каждый день будет состоять из трёх небольших выборов, которые определяют основное действие дня.

## Состояние проекта

Проект находится на ранней стадии разработки:

- описана первая встреча с героиней;
- реализованы основы диалогов, условий выбора и изменения ресурсов;
- игровой цикл на семь дней пока является заготовкой;
- остальные дни, концовки и запись истории игры ещё не реализованы.

Сейчас в проекте также отсутствует функция `main`, а свойство `player` в классе `Game` содержит `TODO()`. Для запуска необходимо создать состояние игрока и добавить точку входа.

## Структура проекта

```text
src/
├── Main.kt          # Точка входа — пока не заполнена
├── Game.kt          # Игровой цикл
├── PlayerState.kt   # Показатели игрока
├── GameEvent.kt     # События и диалоги
├── FirstMeeting.kt  # Первая встреча
├── Day.kt           # Модель дня
└── DayRecord.kt     # Заготовка для записи дня

.md/
├── Plot.md                # Сюжет и концовки
├── Правила и баланс.md    # Замысел игровой механики
├── Methodology.md         # Методические материалы
└── TODO.md                # Задачи проекта
```
